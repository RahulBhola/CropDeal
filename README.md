This is a CropDealing website with three users i.e 

1. Farmer: 
  1.1 Can sell crops
  1.2 profile view
   
2. Dealer
  2.1 Can sell crop
  2.2 Can make payments
  2.3 Can generate invoices
  2.4 Invoices view on profile
  2.5 Invoices sent to himself and farmer via mail
  
3. Admin:
  3.1 Approves Framer Crop before reflecting it to Dealer,
  3.2 view charts to analyse users,
  3.3 can Activate-Deactivate users from login
  3.4 Can View invoices of All Dealer Users

4. Extra Features
   4.1 Identity Services - Authentication and Authorization using Jwt Token, Stored in the form of cookies
   4.2 Email Services - for sending emails for Invoice and Forget Password
   4.3 Forget Password - Users can change password when Forgot
